# Arcade 3D assets

No third-party GLB was used.

All desk hardware (case, fans, internals, monitor, keyboard, mouse) is original in-repo Three.js geometry in `components/arcade/rig/`. It is not a scanned product and not a licensed commercial kit.

Reason: empty `public/models/` stays blocked for unlicensed/hotlinked files. Sketchfab/CGTrader kits were not imported without a clear reusable license on disk.

If a licensed GLB is added later, place it under `public/models/arcade/` and record source, license, and attribution here.
