# Contact planet assets

The Contact section loads the complete stylized Earth directly from:

- `scene.gltf`
- `scene.bin`
- `Planet_baseColor.png`
- `Clouds_baseColor.png`

`scene.gltf` references the binary geometry and both colocated textures. Keep these four files together in this directory so `useGLTF("/models/planet/scene.gltf")` can resolve every dependency automatically.
