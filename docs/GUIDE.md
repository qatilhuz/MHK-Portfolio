# Guided 3D host

Page-level transparent canvas (`pointer-events: none` except raycast hits). Not a dock or card.

Toggle the entire system from `data/characterConfig.ts` (`enabled`).

See `docs/3D-MODEL-LICENSE.md`. Production licensed GLB is **not** in the repo.

Tour, Skip, workspace, and assistant are unchanged. After Skip the host stays and can roam safe zones.
